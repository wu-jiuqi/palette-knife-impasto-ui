# 油画主题游戏 UI Vertical Slice

这是按新版 `palette-knife-impasto-ui` 流程制作的第一版验收成品，不是单纯组件拼贴。

## 运行

直接用浏览器打开 `index.html`，或在此目录运行：

```bash
python -m http.server 4173
```

然后访问 http://localhost:4173/demo/

## 本版验证点

- 整屏视觉身份：斜切框体、非对称构图、红/金/墨绿角色色、倾斜标题
- 前景/中景/背景三层关系
- 主按钮、次级按钮、悬停/焦点/点击反馈
- 基础 toast 转场反馈
- 响应式移动端布局

## v4 组件展示

- 按钮：独立刮刀颜料块面，悬停/按下/点击飞溅
- 搜索栏：横向刮痕纸带，聚焦时抬升并改变投影
- 下拉栏：深色折页结构，展开项有横向位移
- 提示 Chip：印章式小组件
- 提示框：撕纸画布卡片，带模态入场和退出
- Toast：运行时状态反馈，与按钮和搜索输入共用颜料粒子系统

## v6 材质修正

- 移除组件外层纯色背景、border、clip-path 假轮廓
- 生成图直接承担搜索栏、下拉栏、提示框和 Toast 的外形
- 文字改为根据深色油彩安全区使用浅色、阴影和强调色
- 下拉项、提示内容和状态条不再使用纯色矩形包裹
