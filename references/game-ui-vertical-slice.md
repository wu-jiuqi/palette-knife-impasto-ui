# 游戏 UI 整屏视觉切片规范

## 目标

把“有油画材质的资产”升级为“有明确游戏身份的整屏界面”。切片是验收对象，不是只用于沟通的 moodboard。

## 视觉身份卡

生成前必须写清：

- 形状语法：斜切、撕裂、折页、手绘边缘、非对称框体等至少两项。
- 构图语法：主焦点、次焦点、阅读路径、留白和视觉重心。
- 标题系统：字体类别、字重、倾斜/变形、描边/阴影、与图形的组合关系。
- 色彩角色：背景色、主操作色、强调色、危险/禁用色及占比。
- 装饰符号：纹章、笔触、贴纸、印章、花瓣、纸张或其他世界观符号。
- 动效节奏：入场、悬停、按下、转场的时长和位移感。
- 禁用方向：工作台、卡片墙、平均分栏、默认圆角按钮、无意义噪点。

## 切片最低内容

- 一张完整屏幕，而不是孤立组件集合。
- 一个明确主标题和一个主操作。
- 至少一个次级操作或状态反馈。
- 前景、中景、背景三层关系。
- 一个可辨识的交互状态（hover/pressed/selected）。
- 一个真实可运行的转场或反馈。

## 五项硬验收

每项 0–2 分，总分至少 8 分才能进入组件拆分；任何一项为 0 分都必须返工：

1. 3 秒第一眼是否能说出这是一个有独立身份的游戏界面？
2. 是否明显不是网页工作台或普通后台卡片？
3. 主焦点、次焦点和阅读路径是否清晰？
4. 标题、按钮文字和图形是否形成统一排版系统？
5. 悬停、按下或转场是否提供了可感知反馈？

## 回组检查

拆分组件后必须在目标运行时重新检查：比例、层级、文字安全区、透明边缘、缩放、状态差异和动效。单个组件好看不能替代整屏验收。
