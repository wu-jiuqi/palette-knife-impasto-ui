# 刮刀厚涂 UI 风格桥接

本 Skill 继承 `palette-knife-impasto` 的通用风格基线。执行时若宿主提供该 Skill，先读取它的 `references/style-bible.md` 和输入提示词规则；本文件只补充 UI 场景的适配。不要把某个项目的剧情、角色、默认配色或 UI 布局带入其他项目。

## 保留的媒介语言

- 颜料有体积，厚薄随材质和光源变化。
- 宽阔、有方向的刀面塑造面板、边框和装饰的大形体。
- 刀锋边缘断续、有少量堆积和刮开痕迹，不使用均匀噪点代替笔触。
- 粗画布只在薄涂、刮开和局部边缘选择性露出。
- 明暗分组和冷暖关系先于纹理；视觉焦点附近细节更集中。

## UI 适配

- 厚涂重点放在框体、底图、边缘和装饰上，文字与数据区域保持低细节。
- 小图标、窄按钮和触控目标降低刀痕密度，保留轮廓、孔洞、方向和状态差异。
- 通过材质、明暗、局部高光或色彩强调区分 normal、hover、pressed、disabled 等状态，不牺牲可读性。
- 为文字、图标、数值和动态数据预留干净区域；正式文字默认由宿主运行时叠加。
- 需要可拆分的面板时，让内外边缘、九切区或平铺区的纹理连续且不过度依赖单一中心构图。

## 提示词桥接段

可按资源用途拼入以下描述，再补充本次项目的主体、颜色、比例和状态：

> 刮刀厚涂油画 UI 资产，具有真实厚油彩堆积、方向性宽刀面、断续刀锋边缘和选择性露出的粗画布；笔触沿面板结构和装饰轮廓组织，边缘有少量颜料体积高光。文字与数据区域保持低细节、高对比、干净留白，不使用均匀颗粒或滤镜式油画纹理。材质表现服务于轮廓、层级和交互状态的识别。

不要把这段当作完整提示词。还必须说明组件用途、目标比例、状态、透明要求、参考图角色和排除项。

## 风格检查

确认生成结果能看出厚颜料、刀面和局部底布，同时组件轮廓、文字留白、层级和状态仍然清楚。若只剩平面纹理，或纹理吞掉识别结构，应降低纹理密度并进行一次定向修订。
